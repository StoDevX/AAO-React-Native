# Getting started

Set up the repo and run the app on a simulator.

## Overview

This is a plain **article**: prose, headings, code blocks, asides, and lists.

```bash
mise run agent:setup
APP_VARIANT=aao-dev mise run aao:ios
```

> Note: An aside like this renders as a callout. Also supported: `Important`,
> `Warning`, `Tip`, and `Experiment`.

### Variants

| `APP_VARIANT` | Home screen |
| --- | --- |
| `aao` | All About Olaf |
| `carls` | CARLS |
